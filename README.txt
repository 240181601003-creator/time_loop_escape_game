TIME LOOP ESCAPE — Neon Futuristic Maze

REQUIREMENTS
- Python 3.10 or newer
- Pygame

INSTALL
Open Command Prompt / Terminal in this folder and run:
    python -m pip install pygame

PLAY
    python time_loop_escape.py

CONTROLS
- WASD or Arrow keys: move
- R: rewind and generate a new maze
- Space: pause/resume
- Enter: restart after winning or game over
- Esc: quit

OBJECTIVE
Collect the yellow key, then reach the exit before the 30-second loop timer expires.
When the timer runs out, you lose one life and the maze shifts. Your previous run is
shown as a pink ghost replay. Rewind lets you restart the current loop without losing
a life, but the maze changes.
